# 问题修复与安全复测

日期：2026-10-21。范围：当前功能收敛分支，不修改 main，不提交或推送代码，不改变数据库目录。

## 已修复

1. **聊天跨人物串流与中断保存错位**
   - 每次请求绑定 requestId、characterId、sessionId，数据库验证会话所属人物。
   - 新建、切换、删除人物或删除聊天历史前，先等待当前请求停止并完成保存。
   - 前端先注册事件监听再发请求；使用请求版本隔离迟到事件和迟到的返回结果，阻止重复发送。
   - 停止失败时保留请求锁，允许重试，不继续切换人物。
2. **停止生成没有真正取消网络读取**
   - 后端取消信号直接终止等待中的 HTTP 请求或响应读取，丢弃网络流。
   - 后端使用收到的完整部分内容保存中断记录，避免前端打字机尚未显示的文字丢失。
   - 停止后隐藏不完整动作标签、工具调用片段。
   - 本地断开不代表能够保证所有服务商立即停止计费，计费以服务商规则为准。
3. **中文流式回复乱码**
   - 跨网络分块保留原始字节，完整行到齐后才按 UTF-8 解码。
   - 测试覆盖中文、emoji 在每个可能字节边界被拆开的情况。
4. **测试连接会覆盖正式配置、HTTP 200 被误判为成功**
   - “测试连接”只使用当前草稿，既不保存，也不启用配置；只有“保存并使用”才持久化。
   - 复用旧密钥时校验地址来源，换域名需重新填 Key，防止误发。
   - 校验 Chat Completions JSON 和非空文字回复，拒绝 HTML 页面、错误对象、空回复。
   - 限制测试与错误响应大小、消息长度、超时和模型参数，错误响应中的当前 API Key 会被脱敏。
5. **素材覆盖失败会破坏旧素材**
   - 先在临时兄弟目录复制完整图片及元数据，成功后才替换目标目录。
   - 替换使用备份和失败回滚；复制失败时旧素材及元数据不变。
   - 隐藏导入中目录，拒绝从待覆盖目录内部进行覆盖导入。
6. **密钥明文存储与页面权限过宽**
   - Windows 使用系统凭据管理器，macOS 接入钥匙串；数据库仅存不透明引用。
   - 旧明文密钥启动时迁移，写入并读回验证后才更新数据库；新密钥保存失败不覆盖原配置。
   - 前端只能获知是否有密钥，不能读取完整密钥。
   - 启用 CSP；本地资产协议仅允许读取应用的 skins 目录，不再暴露整个应用数据目录。
7. **托盘恢复窗口**
   - 点击托盘或“显示工具箱”会恢复已最小化窗口，再显示工具箱。

## 依赖安全复测

- 升级 Vite 至 8.3.4、Vitest 至 5.0.5，并更新相关构建、测试、检查依赖及安全修补版本覆盖规则。
- Tauri Rust/API 均更新至 2.12.4，避免前后端版本不匹配；更新 Cargo.lock 中兼容版本依赖。
- 网络相关修补包括 h2 0.4.20、rustls 0.23.46、rustls-webpki 0.103.16、webpki-roots 1.0.10；同时更新 anyhow、event-listener、quick-xml、quinn-proto、serde_with 等。
- `pnpm audit --prod`：未发现已知漏洞。
- 完整 pnpm 扫描：剩余 **1 个 high 公告**，来自 Tailwind 3 的开发间接依赖 braces 3.0.3，当前公告没有修复版本。风险是恶意嵌套模式触发开发工具栈耗尽，不属于应用生产包运行依赖。开发环境仅处理可信项目文件，Vite 保持监听 127.0.0.1；暂不为清零扫描结果而进行 Tailwind 4 大迁移。
- OSV 批量检查当前 Cargo.lock 的 **546 个 crates.io 包**：剩余 glib 0.18.5 的已知问题，以及 proc-macro-error、zbus_names、zvariant、zvariant_derive 的停止维护公告。
- 使用 Windows 目标的 cargo tree 核验，上述 5 个包均未进入当前 Windows 依赖树。Linux 相关依赖仍需跟踪上游，不将全平台扫描描述为零风险。

来源：[OSV API](https://google.github.io/osv.dev/api/)、[glib 公告](https://rustsec.org/advisories/RUSTSEC-2024-0429.html)、[braces 公告](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)、[Tauri CSP](https://v2.tauri.app/security/csp/)、[keyring 存储接口](https://docs.rs/keyring/3.6.3/keyring/struct.Entry.html)。
