# 功能收敛测试报告

日期：2026-10-20
本地分支：codex/simplify-companion

## 本次改动

- 删除喂食、食物库存与替换、状态面板、能量、好感、掉落、每日结算、隐藏奖励及作弊重置的界面与运行代码。
- 保留自主移动、拖拽与抛出、哄睡、聊天动作、角色管理、记忆和主题。
- 移除导入资源必须包含 eat_food 动作的要求；旧资源包仍可使用。
- 默认连接固定为 DeepSeek 官方地址和 deepseek-flash，用户只需填 Key。默认关闭深度思考。
- 高级设置只保留一组自定义连接：Base URL、模型名、Key，统一使用 OpenAI 兼容的 Chat Completions 协议。
- 删除 Gemini、Anthropic 和 Ollama 原生适配器及厂商预设列表。Ollama 等可通过兼容地址接入。
- 补充聊天失败时的可见提示，可直接打开连接设置。

## 后续支持范围

DeepSeek 是主要维护和测试对象。高级自定义接口按 OpenAI 兼容 Chat Completions 协议接入，由用户自行填写并验证地址、模型名和 Key。项目维护通用接口逻辑，不逐家适配其他厂商的原生协议，也不保证所有兼容服务始终可用。

虽然不逐家适配，仍欢迎通过 [Issue](https://github.com/Li-Rui-Zhe/BytePet/issues) 反馈使用体验和兼容性问题。后续根据问题的通用性、影响范围和维护成本评估改进，不承诺逐家提供适配。反馈应附复现步骤和脱敏错误信息，不应包含 API Key 或其他敏感内容。

## 数据兼容

- 角色与聊天记录继续使用原数据库。
- 旧版已启用的兼容连接会迁入自定义槽位；原生协议配置保留但停用。
- 旧喂食和状态表保留历史内容，新版不再读取、更新或结算；新数据库不创建这些表。
- DeepSeek 与自定义接口分别保存 Key，空输入保留原 Key；自定义接口换到另一个服务地址时要求重新输入 Key。
- 原 DeepSeek 配置如果使用了代理地址，迁移时将其配置和密钥一起归档，避免把代理密钥发送到官方服务。
- 修改前数据库已备份到本项目 data/backups/before-simplify-verified.db，并校验文件一致。
- data/ 已加入 Git 和开发工具的忽略范围。本次没有提交或推送。
