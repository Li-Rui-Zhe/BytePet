# DeepSeek 新手指南

核对日期：2026-10-25。独立「指南」分为「先开始」「连接 AI」「问题排查」，可离线阅读。设置中的指南入口会直接打开「连接 AI」。

首次启动会显示三个简短介绍，随时可以跳过，暂不填写 Key 也能使用本地陪伴功能。完成、跳过或关闭后会在当前应用用户环境记住状态；可从「指南」重新查看。清除应用的网页存储后，引导可能再次出现。

普通用户使用默认 DeepSeek 即可，只需要自己的 API Key，不用配置接口地址或模型。高级自定义接口留给了解相关服务的用户自行 DIY。

## 开始前：分清聊天网页与 API

桌宠连接的是 DeepSeek 开放平台 API，不是把 DeepSeek 聊天网页嵌入桌面。网页版可以聊天，不代表 API 一定有可用额度。

API 按用量计费，连接测试也会发起一条短请求，可能产生少量费用。费用与可用额度以 DeepSeek 官方平台为准；不在教程中写死价格，也不要求固定充值金额。是否充值、充值多少由你决定。

- [DeepSeek 开放平台密钥管理](https://platform.deepseek.com/api_keys)
- [账户余额](https://platform.deepseek.com/balance)
- [官方计费说明](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

## 第一步：打开官方平台

1. 在桌宠的 DeepSeek 设置中点击「获取 API Key」，使用系统默认浏览器打开官方密钥管理页。
2. 注册或登录自己的 DeepSeek 账号。如果登录后没有回到密钥页，在平台中找到「API keys / API 密钥」。
3. 认准 `platform.deepseek.com`。如果按钮无法打开浏览器，可手动访问上面的官方链接。

桌宠不会替你登录、索要登录验证码，也不会读取浏览器中的密钥。

## 第二步：创建和复制密钥

1. 在官方平台创建新密钥，名称可填写「桌宠」。
2. 在创建结果页面使用官方复制按钮，复制完整 API Key。
3. 不要只复制已遮挡的片段；若无法再查看完整密钥，创建一个新密钥，并按需撤销旧密钥。

Key 是 API 调用凭证，不是账号密码。不要将 Key 发给他人、放入截图、Issue、日志或代码仓库；泄露后应立即在官方平台撤销并更换。

## 第三步：粘贴到桌宠

1. 回到桌宠「设置」。如果已经勾选「使用自定义接口」，取消勾选，或点击「新手建议：切回 DeepSeek」。这一步只切换编辑草稿，不会立即改变已启用连接。
2. 在「DeepSeek API Key」输入框中粘贴：Windows 使用 `Ctrl + V`，macOS 使用 `⌘ + V`。
3. 只粘贴密钥本身，不加 `Bearer`、引号、接口地址或账号密码。
4. 默认连接内置地址 `https://api.deepseek.com`。聊天模型默认 `deepseek-flash`，也可直接选择列表中的其他 DeepSeek 模型，不必切换自定义接口。

## 第四步：测试、保存、聊天

1. 点击「测试连接」，等到成功提示。测试不会保存草稿，也不会切换当前连接。
2. 测试通过后点击「保存并使用」。
3. 确认提示所选配置已保存并启用，顶部当前配置显示你设置的名称；默认名称是 DeepSeek。
4. 关闭设置，进入聊天，发送一句简短的话。

测试成功表示该次测试请求返回了有效回复，不保证后续所有请求都成功。网络、账户额度、服务状态仍可能变化。

## 多个密钥与模型切换

- 点击「新增配置」，分别填写备注名称、模型和 Key，例如「日常使用」「备用账户」。新增配置不会自动继承其他配置的密钥。
- 已保存列表显示名称、模型、脱敏密钥标识和当前启用状态，完整 Key 不会回传到界面。
- 「仅保存，不切换」不会切换当前配置；修改正在启用的配置并保存，会影响后续聊天。「保存并使用」会保存并启用该配置。
- 列表上的「启用」只使用已保存的信息，不会悄悄保存正在编辑的草稿。一次只启用一个配置。
- 修改 DeepSeek 模型时可沿用此配置已保存的 Key；测试验证草稿，保存后才生效。
- 删除配置需点击再次确认；不能直接删除当前启用配置，先启用另一配置再删除。删除只影响本地，不撤销平台密钥。

## 密钥保存与更换

- Windows 使用系统凭据管理器，macOS 接入系统钥匙串；数据库保存不透明引用，不向前端返回完整已存 Key。
- 已保存时输入框留空表示沿用原 Key；眼睛按钮只显示当前输入的内容，不会读回系统保存的 Key。
- 填入新 Key 后点击「保存并使用」可更新本地凭据。
- 删除本地配置及 Key 不会撤销官方平台上的 Key；撤销要到 DeepSeek 平台操作。
- 换电脑、换系统账号或丢失系统凭据时，重新填写 Key。复制数据库不等于复制了系统凭据。
- 未配置 API 不影响本地角色显示与互动，但不能使用 AI 聊天。

## 常见问题

| 情况 | 建议 |
| --- | --- |
| 未填写 Key | 从开放平台创建并复制完整 Key 后粘贴 |
| 401 / 认证失败 | 检查 Key 是否完整、是否被撤销，去除误加的前缀和引号；必要时新建 Key |
| 402 / 余额不足 | 查看 API 账户可用余额，是否充值自行决定 |
| 400 / 422 / 参数错误 | 选择内置 DeepSeek 模型；自定义接口核对模型 ID、接口地址及 Chat Completions 支持情况 |
| 429 / 限流 | 稍等后重试，避免连续点击测试 |
| 500 / 503 | 官方服务可能故障或繁忙，稍后重试 |
| 超时 / 网络连接失败 | 检查网络、系统代理、防火墙，以及能否打开官方平台 |
| 测试成功但未启用 | 还需要点击「保存并使用」，并核对顶部当前连接 |
| 自定义接口返回 HTML / 空回复 | 确认填写的是兼容 API 地址，不是聊天网页；检查模型名称和服务文档 |

进一步排查可阅读[官方错误码说明](https://api-docs.deepseek.com/zh-cn/quick_start/error_codes/)和[官方 API 文档](https://api-docs.deepseek.com/zh-cn/)。反馈时只提供脱敏后的错误信息，不发送真实 Key 或私人聊天内容。

## 高级用户 DIY 范围

项目主要维护和测试 DeepSeek；高级设置提供一套通用的 OpenAI 兼容 Chat Completions 连接，不逐家适配其他厂商的原生协议。

启用自定义接口后，由用户自行确认：

- **Base URL**：服务商的兼容 API 地址。程序会追加 `/chat/completions`，也可以填写完整 Chat Completions 地址；不要填写带账号密码或密钥查询参数的网址。
- **模型名称**：服务端真实可用的模型 ID，不是随意起的显示名称。
- **API Key**：对应服务的调用密钥；明确免鉴权的本地接口才可留空。跨服务换地址时不要沿用原服务的 Key。
- **协议限制**：当前是文字 Chat Completions 与流式文本回复，不是任意 HTTP 请求编辑器。特殊签名、自定义鉴权、不同原生协议或特殊参数，可能需要用户自行使用兼容网关，不能保证直接接入。

项目仍维护通用连接层、错误处理和安全逻辑，但不承诺所有兼容服务或模型一直可用。虽然不逐家适配，仍欢迎提交 [Issue 与反馈](https://github.com/hub12345666/BytePet/issues)，会根据通用性、影响范围和维护成本评估是否改进。
