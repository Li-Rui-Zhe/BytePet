# DeepSeek 新手引导测试报告

日期：2026-10-22。基于 `codex/simplify-companion` 当前工作区进行增量修改，不修改 main，不提交或推送。

## 实现内容

- 设置提供「获取 API Key」与「新手指南」入口。普通用户仍默认使用 DeepSeek，无需编辑地址和模型。
- 应用内教程支持离线阅读：官方平台注册登录、创建并复制完整 Key、回到桌宠粘贴、测试、保存与开始聊天。
- 提供密钥管理、余额、官方文档、计费说明、错误码页面的系统浏览器入口；打开失败时显示可手动访问的网址。
- 说明 API 按量计费、测试可能产生少量费用、测试不保存草稿；不写死价格，不要求固定充值金额。
- 补充 401、402、429、5xx、网络超时、未保存连接等排错说明，以及密钥泄露与换电脑注意事项。
- 阅读教程再返回，保持当前连接草稿；输入过的密钥恢复遮挡，不读取已保存的系统密钥。
- 高级设置注明 DIY、通用 OpenAI 兼容协议、用户自行确认配置、不逐家适配，并保留反馈欢迎说明及切回 DeepSeek 入口。
- 增加独立 Markdown 教程并链接到 README，修正反馈入口至当前仓库。

## 维护边界与未验证项

- 主要维护和测试 DeepSeek，同时继续维护通用连接层的协议、网络和安全逻辑。不承诺所有自定义服务永久兼容或完全零维护。
- 本轮只使用本地模拟 HTTP 服务和非真实测试凭据，没有调用用户的付费 DeepSeek API；真实账号的余额、鉴权与服务可用性需用户填入自己的 Key 后测试。
- Windows 原生路径已实测；macOS 浏览器调用沿用 `/usr/bin/open`，未做 macOS 实机验证。
- 没有新增供应商适配器，没有引入新的包依赖，没有迁移数据库目录。
- 教程不会自动读取或复制浏览器中的 Key，也不会读取用户剪贴板。复制在官方平台完成，粘贴由用户操作。
- 本轮未删除旧数据、未推送密钥或代码；上一轮报告中的上游开发依赖和非 Windows 平台依赖风险仍需持续跟踪。
