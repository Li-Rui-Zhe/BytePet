# BytePet main 更新说明

日期：2026-10-25。此次为功能收敛、可靠性修复和跨平台测试包准备，不是新的正式 Release。项目版本号仍为 `0.1.0`，不创建或覆盖现有版本标签。

## 本次改动

### 收敛为桌面陪伴与聊天

- 移除用户可见的喂食、食物库存、好感与能量状态及对应结算逻辑，删除不再使用的组件、规则和素材。
- 保留桌宠拖动、抛出、落地、睡眠、唤醒、动作、人物档案、聊天、素材导入、主题、托盘与本地存储。
- 不在本轮改造素材导入规范，也不恢复之前的 SVG、Rive、Spine、Blender 实验分支内容。

### AI 配置与新手使用

- 默认只维护和测试 DeepSeek 内置接入；高级设置支持通用 OpenAI 兼容 Chat Completions 接口，不承诺逐家适配或未来永久兼容。欢迎提交 Issue、复现信息和适配反馈。
- 支持多个具名配置，以脱敏标识展示密钥，分别保存、测试、删除和启用；同一时刻仅一份配置用于聊天。
- API Key 保存在操作系统凭据库 / 钥匙串，数据库只存不透明引用；更换服务地址时避免把原密钥发送给其他主机。
- 增加独立指南、DeepSeek 接入步骤与可跳过的轻量首次引导。连接测试可能产生少量 API 费用，以服务商规则为准。

### UI、交互与可靠性

- 统一面板、按钮、滑块、滚动条和间距，收紧聊天与设置布局，改善窄面板和中文输入法体验。
- 修复聊天取消、流式 Unicode、跨人物上下文、配置草稿保留、复制结果反馈等问题。
- 修复拖动抛出速度与缩放边界、异步尺寸保存、鼠标穿透及托盘恢复问题。
- 开心动作 6 帧复用同一角色原始像素补齐头顶天线圆球，不重绘整个人物。

### Windows / macOS 与构建

- 增加 Mac 原生窗口、菜单栏、Retina 与主屏可用区域处理；最低 macOS 13.3。
- 同一 GitHub Actions 流程并行构建 Windows x64 EXE / MSI、Mac Intel 与 Apple Silicon DMG / app.zip，并提供 SHA-256 校验值。
- 推送 main 自动构建，也可手动运行或推送匹配版本号的 `v*` 标签。其他开发分支不自动构建，main 同分支重复运行会取消旧的未完成任务。
- 产物在该次 Actions 的 Artifacts 中保留 14 天，不自动发布到 Releases。Windows 未代码签名；Mac 为 ad-hoc 签名，未做 Apple 公证。

## 数据与安全边界

- 不变更当前默认用户数据目录，不把用户数据迁入源码目录。
- 不提交 API Key、私钥、数据库、备份、日志、缓存、node_modules、target 或本地测试截图；本地敏感数据应继续保留在忽略范围。
- 旧数据库中的历史养成数据迁移以保留兼容为主，不执行清空用户数据库的操作。
- 本次只进行正常 Git 提交及快进推送，不强推、不重写远端历史；推送前基线为 `bfd8a464d65a7ebc182a277039c009861cf4bb98`。

## 本地验证与待验收

本地已通过：类型检查、lint、前端构建、64 项前端测试、42 项 Rust 常规测试及单独 1 项系统凭据测试；Windows / Mac 合并配置使用实际锁定的 Tauri 版本严格解析通过。常见敏感模式和忽略规则扫描未发现待提交问题，但这不是无漏洞保证。

首次云端构建仍可能暴露 runner 或打包工具问题；必须确认三个任务全部通过，再下载测试。实际 Windows 安装 / 卸载 / 升级，以及两种 Mac 架构的窗口、菜单栏、Dock、素材和钥匙串体验仍需验收，不以进程存活代替完整测试。

详见 [跨平台打包指南](跨平台Actions打包指南.md)、[本地打包流程测试报告](跨平台打包流程测试报告-2026-10-25.md)及各阶段测试报告。

## 后续发布与回退

本次推送不等于发布新版本。准备正式发布时，先同步 package.json、src-tauri/Cargo.toml、src-tauri/tauri.conf.json 的版本号，验证安装包后再决定新标签和 Release。

如需撤销本次源码更新，应在 main 上对本次提交创建 `git revert` 反向提交，经检查后正常推送；不要使用强制推送覆盖他人的提交。回退代码不会自动还原数据库迁移或用户数据，涉及数据恢复时应先单独备份和评估。
