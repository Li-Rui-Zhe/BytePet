# 紧凑面板与聊天布局测试报告

日期：2026-10-25。范围：桌面面板的空间分配、导航和聊天输入区。保留现有主题、素材要求、人物、聊天连接及数据逻辑，不提交或推送代码。

## 改动

- 共用页头改为标题和说明同一行；长说明省略显示，鼠标悬停可阅读完整内容。导航改为 32px 高的图标加文字单行排列；窄面板保留六个文字入口、隐藏图标，不隐藏功能。
- 共用面板内边距由 16px 调整为 14px，卡片由 14px 调整为 12px，统一收紧导航、页头和设置字段间距，不缩小正文来换取空间。
- 聊天默认尺寸由 400×560 调整为 380×480；设置 380×560、记忆 380×540、人物 380×580、主题 380×560、指南 400×580、引导 380×420。保留手动调整面板尺寸能力。
- 聊天输入默认两行（42px），随草稿增高，最多 126px，超过后内部滚动；短屏进一步限制高度。清空或切换到短草稿时自动收回；面板宽度变化时重新计算换行高度。
- 移除整行发送／停止按钮，改为输入区右下角的 30px 图标按钮，提供无障碍名称、悬停提示和键盘焦点。空草稿、等待发送、无人物和停止中的禁用规则保留。
- 保留 Enter 发送、Shift＋Enter 换行，新增输入法组合输入及 Windows keyCode 229 保护，避免确认中文候选词时误发送。
- 聊天气泡间距、背景和内边距轻微收紧；错误与等待提示可滚动，不无限挤占消息区域。未改聊天持久化、请求取消和密钥保存逻辑。
