# BytePet v0.2.0

这次更新将 BytePet 从「聊天 + 养成数值」收敛为更轻量的桌面陪伴工具：减少需要照顾的状态，把重点放在角色互动、聊天配置、使用引导和可靠性上。

以下对比以仓库 `v0.1.0` 标签代码为基线，不把开发中尝试过但未保留的功能计入本次发布。

## 相比 v0.1.0 改善了什么

| 方面 | v0.1.0 | v0.2.0 |
| --- | --- | --- |
| 产品功能 | 喂食、库存、好感、能量、每日结算等养成逻辑 | 移除这些数值与管理负担，保留桌面陪伴、动作和聊天 |
| AI 接入 | 多厂商预设与多种协议分别维护 | 默认 DeepSeek；高级用户配置通用 OpenAI 兼容 Chat Completions 接口 |
| 连接管理 | 主要按厂商配置 | 可保存多份具名连接，展示脱敏密钥标识，分别测试、删除和启用；一次启用一份 |
| 密钥存储 | 数据库中的密钥字段 | 系统凭据库 / 钥匙串保存密钥，数据库保存不透明引用 |
| 初次使用 | 主要依赖用户自行配置 | 可跳过的首次引导、独立使用指南、DeepSeek 接入步骤和问题排查 |
| 面板体验 | 布局与控件样式较分散 | 统一按钮、滑块、滚动条、卡片和间距，缩小默认面板，改善窄窗口布局 |
| 跨平台 | 以 Windows 为主 | 增加 Mac 原生适配与 Intel / Apple Silicon 分别构建；macOS 仍为实验性支持 |
| 打包 | 早期分发流程 | 三平台并行构建，平台校验、启动检查、包校验值与版本标签发布流程 |

## 新增与优化

### 更轻量的桌面陪伴

- 保留拖动、抛出、落地、睡眠、唤醒和自主动作，不配置 API Key 也可以先使用桌宠。
- 移除喂食、食物库存、好感、能量以及相关状态面板、结算规则和冗余素材。
- 保留人物档案、独立聊天记录、PNG 序列帧素材导入、主题与托盘功能；素材导入规范本轮没有重新设计。

### 更集中、更安全的 AI 配置

- 默认使用 DeepSeek，支持内置模型选择；高级设置手动填写 Base URL、模型 ID 和 API Key。
- 同一服务可以保存多份具名配置，密钥列表只展示脱敏标识；支持保存、测试和单独启用。
- 更换服务地址时，不会直接沿用并发送原主机的密钥；连接测试不自动保存配置。
- API Key 改用 Windows 系统凭据库 / macOS 钥匙串，避免将完整密钥回传设置界面。
- 官方维护范围收敛为 DeepSeek。其他服务需兼容 OpenAI Chat Completions；不承诺逐家适配或永久兼容，但欢迎提交 Issue、复现信息和适配反馈。

### 引导与界面

- 首次启动提供可跳过、之后可重新打开的轻量引导。
- 指南与设置分开展示，包含获取 DeepSeek API Key、保存连接、聊天及常见错误说明。
- 统一交互控件和色调规则，收紧聊天输入区域及面板布局，改善窄面板可读性。
- 改善中文输入法确认候选时误发送、草稿保留、错误提示和复制结果反馈。

## 重点修复

- 修复拖动抛出速度取样、长按后误甩动、缩放边界及异步尺寸保存竞争问题。
- 修复流式回复 Unicode 分块、停止请求、取消与收尾竞争，以及跨人物聊天状态隔离问题。
- 修复托盘恢复、窗口焦点与鼠标穿透缓存不同步，降低「界面出现但无法点击」的风险。
- 修复素材导入失败时覆盖旧资源的风险，导入采用暂存与完整发布流程。
- 修复默认角色开心动作 6 帧缺失头顶天线圆球的问题，复用原角色像素保持一致性。

## 下载哪个包

- Windows 10 / 11 x64：下载 `BytePet_0.2.0_x64-setup.exe`。
- Mac M 系列：下载名称含 `arm64` 的 DMG；Mac Intel：下载含 `x86_64` 的 DMG。最低 macOS 13.3。
- 打开 Mac DMG 后先把应用拖入「应用程序」，再从本机启动。
- 附带 `SHA256SUMS.txt`，可用于核对下载完整性。
- Windows MSI 和 Mac `.app.zip` 作为备用保留在 [本版本 Actions 构建产物](https://github.com/Li-Rui-Zhe/BytePet/actions/runs/40202856509)，不放在 Release 下载列表；Artifacts 通常保留 14 天，过期后需要重新构建。
- GitHub 自动生成的两个 Source code 下载项是源码，不是应用安装包，普通用户无需下载。

## 升级与兼容性提醒

- 建议升级前退出旧应用，备份本机数据目录，并确保仍能从服务商处获取自己的 API Key。密钥进入系统凭据库后，仅复制数据库不等于完整迁移凭据。
- 默认数据目录沿用系统用户数据目录，不强制迁移到 D 盘、不随安装包提交数据；历史养成数据以兼容保留为主，新版不再展示或结算。
- 旧版 Gemini / Claude 等原生协议不再内置支持。需要这些服务的用户应自行使用兼容 Chat Completions 的入口，重新检查地址、模型和密钥；不会把旧厂商密钥自动发送到 DeepSeek。
- 使用 AI 会将必要的对话上下文发给你选择的接口服务。API Key 申请、费用和隐私政策以服务商为准；连接测试也可能计费。
- 「记忆」当前主要是聊天记录与人物存档查看，不代表自动永久记忆所有对话。
- 不建议无备份直接降级覆盖旧版本；代码回退不会自动回退数据库与系统凭据变化。

## 已知限制与平台说明

- Windows 安装包未配置开发者代码签名，可能触发 SmartScreen；缺少 WebView2 时安装器需要联网下载，当前不是完整离线包。
- **macOS 为实验性支持**：包采用 ad-hoc 签名，未完成 Developer ID 签名或 Apple 公证，仍需实际 Mac 验证窗口、菜单栏、Dock、钥匙串及升级体验。构建与启动检查不等于全面真机验收。
- 先确认下载来源和校验值；不要全局关闭系统安全保护。Mac 安全提示处理参见 [Apple 官方说明](https://support.apple.com/en-us/102445)。
- 桌宠以主显示器可用区域为活动范围，不承诺跨屏行走；素材制作门槛暂未降低，也没有加入语音或 3D 骨骼系统。
- 本地测试覆盖类型检查、lint、前端构建、交互 / 配置 / 数据库回归测试；发布流程只会在三个平台构建与包校验均成功后发布安装包，不保证所有硬件环境无问题。
