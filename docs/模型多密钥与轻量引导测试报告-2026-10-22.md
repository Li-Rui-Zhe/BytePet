# 模型、多密钥与轻量引导测试报告

日期：2026-10-22。分支：`codex/simplify-companion`。本轮不提交、不推送，不修改 main。

## 需求与实现

### 1. DeepSeek 模型直接选择

- DeepSeek 设置提供独立的「聊天模型」下拉框，不必打开 DIY 自定义接口。
- 内置 `deepseek-flash`（默认）和 `deepseek-v4-pro`。模型 ID 核对于 [DeepSeek 官方调用文档](https://api-docs.deepseek.com/quick_start/pricing)。不在应用中写死价格。
- 前后端共享 `src/config/deepseekModels.json`；Rust 校验官方模式的模型列表，避免界面选了模型而后端仍强行覆盖为默认模型。
- 模型选择按配置保存、重新打开可恢复。修改模型可保留该配置原 Key；测试不保存草稿。
- DeepSeek 配置仍固定官方地址，关闭深度思考；自定义接口保持通用 Chat Completions 协议和任意模型 ID。

### 2. 多个具名配置，一个启用

- 可新增多个 DeepSeek 或自定义配置，分别保存名称、模型、接口和系统凭据引用。
- 名称限制 1–40 个字符；新增配置使用独立 UUID，不继承其他配置的密钥。
- 列表只展示配置名称、模型、脱敏密钥标识和启用状态。较长密钥最多显示末四个字符；短密钥全部遮挡，完整值不回传界面。
- 沿用既有数据库表，不新增存储明文密钥的字段。完整密钥仍由系统凭据库保存，数据库只保存不透明引用。
- 「仅保存」不切换当前配置；但修改本来就已启用的配置并保存会影响后续聊天。「保存并使用」保存并启用该配置；列表「启用」只使用已保存信息，不提交其他草稿。
- 同一时间仅有一个全局启用配置，切换用于后续聊天，不做多角色绑定或并行调用。
- 删除需要再次确认；后端也禁止删除正在启用的配置，要求先切换。删除非活动配置不影响其他配置，仅在引用不再使用时清理系统凭据。不会撤销服务商平台上的密钥。
- 旧原生厂商和归档配置不重新作为可启用选项出现。

### 3. 指南独立、入门轻量

- 完整教程位于独立「指南」页，设置保留跳转入口。设置与指南间往返时保留未保存草稿，密钥仍默认遮挡。
- 首次运行这套引导时，初始化完成后显示三个短步骤：基本互动、本地功能无需 Key、按需配置 AI。
- 随时可以跳过或关闭，不要求注册、填 Key、测试连接或充值；不会因打开引导自动调用模型。
- 完成、跳过或关闭后，在当前应用的用户网页存储中记录布尔标志；不保存密钥或聊天数据。老用户尚无该标志时也会看到一次。清除此存储可能再次显示引导。
- 「指南」可主动重新打开入门引导；普通启动不会反复强制展示。存储不可用时不阻止进入应用。
- 更新 README 与 DeepSeek 教程，并明确 AI 聊天需要向所选 API 服务发送必要上下文，避免误写为聊天数据永不离开本机。

## 边界

- 自动测试使用内存数据库、测试凭据替身及本地模拟 HTTP；未使用用户密钥进行付费 API 调用，也未替用户新增或删除真实密钥配置。
- 已启动真实 Windows 开发窗口；本轮不把组件渲染测试和进程启动检查描述为完整端到端点击验收。macOS 钥匙串权限、多显示器和各模型实际服务端响应仍需相应实机验证。
- 未安装应用或依赖，未更改数据库目录。此前记录的上游依赖告警仍保留。
- 密钥检查只针对候选文件常见敏感模式，不等于完整历史安全审计。
