# UI、指南优化与推送前复查

日期：2026-10-25。分支：`codex/simplify-companion`。结论：本轮已验证的 Windows 开发版本可以准备提交、推送到开发分支；这不等同于已完成正式安装包发布或 macOS 实机验收。没有暂存、提交、创建标签或推送。

## 本轮优化

### 指南的阅读路径

- 独立指南改为「先开始」「连接 AI」「问题排查」三个分类，固定在内容滚动区之外，286px 窄面板仍为单行。
- 默认先介绍不需要 API 的本地陪伴，说明拖拽、抛出、哄睡、工具箱恢复、退出和调整面板尺寸。
- 设置内的教程入口直接进入「连接 AI」，返回设置时保留原来尚未保存的编辑草稿。
- DeepSeek 教程保留四步：登录官方平台、创建并复制完整 Key、粘贴并测试、保存并使用。不替用户登录，不读取浏览器 Key，不自动调用 API。
- 多密钥、更换与删除 Key 改为按需展开；错误排查单独展示，补充 400／422、错误接口地址、数据位置、托盘恢复等说明。
- 删除过时的固定成功提示文案，统一「正在使用」「仅保存，不切换」等真实按钮名称。
- 明确「记忆」是聊天记录与人物存档入口，不夸大为已经实现自动永久记忆。
- 指南正文和备用网址允许选择复制；外部链接仅通过已有官方地址白名单打开。失败时显示可手动访问的地址。
- 分类切换和引导翻页回到内容顶部；共用面板支持在内部按 Esc 关闭，中文输入法组合期间不误关闭。补充折叠标题的键盘焦点样式。

### 文档与构建

- 同步应用内教程、仓库教程和 README。README 明确区分当前开发分支与已发布 v0.1.0 安装包，避免下载旧包后误以为包含新功能。
- macOS workflow 原来的 Node 20 不满足当前依赖要求，调整为 Node 24 和 pnpm 10。运行器调整为官方当前提供的 `macos-15-intel`／`macos-15`，增加 lint 和 Rust 测试。仅修改配置，本轮没有触发 GitHub Actions。
- 三处应用版本配置仍一致为 `0.1.0`；本轮没有自行决定新的发布版本、修改标签或发布安装包。

## 安全与依赖

- 本轮新发现 Tokio 1.54.0 对应 `RUSTSEC-2026-0384`／`GHSA-5wjr-9356-4wc8`。已将最低依赖与锁文件更新到 1.54.1，随后重跑测试和 OSV 检查，该公告不再命中。
- `pnpm audit --json`：全部 JS 依赖、仅生产依赖两种检查均为 0 个已知公告。此前报告的开发依赖公告不再出现在本次审计结果中，历史报告保留其当时结论。
- Cargo.lock 的 546 个 registry 包经过 OSV 查询。剩余 5 个包存在公告：glib 0.18.5 的健全性问题，以及 proc-macro-error、zbus_names、zvariant、zvariant_derive 的停止维护公告。通过 Windows 目标依赖树确认，这五个包不在当前 Windows 目标树中。未以强制跨大版本升级、删除公告或屏蔽告警代替修复；其他平台仍需继续跟踪。
- 候选提交文件常见私钥／API Key／GitHub Token／AWS Key 模式扫描未命中；没有发现数据库、日志、环境密钥文件、浏览器 QA 配置或超大文件混入候选提交集合。
- `git ls-files -ci --exclude-standard` 无输出：没有已被跟踪但又符合当前忽略规则的文件。16 项敏感与构建路径的忽略规则样例通过。
- 已显式运行 Windows 系统凭据真实读写测试：仅创建、读取、删除一个随机名称的测试凭据，结果通过。未读取用户真实 Key、未修改用户真实配置或聊天数据库。

## 后续推送注意事项

1. 提交当前开发分支即可，不需要为了推代码直接合并 main 或创建发布标签。
2. 新增源代码、共享配置、测试和文档仍是未跟踪文件，提交时必须一并包含；只提交已跟踪文件会缺模块。
3. 不提交真实 Key、数据库、旧备份、日志和 QA 浏览器目录；敏感内容如确需公开仍须用户明确同意。
4. 本轮未调用付费模型。真实 DeepSeek 账户聊天、macOS 原生窗口、多屏／DPI、安装包升级和签名未完成新一轮实机验收。
5. 正式发布安装包前再确认版本号、变更日志及 Windows／macOS 验收。已知非 Windows 依赖公告需继续跟踪，不能描述为「绝对没有漏洞」。
