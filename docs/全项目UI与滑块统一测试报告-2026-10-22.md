# 全项目 UI 与滑块统一测试报告

日期：2026-10-22。范围：滑块、滚动条和全项目主要界面的共享控件。保留既有主题选择、角色素材、导入要求、模型连接和数据库逻辑，不提交或推送。

## 共享控件规范

- 常规输入框、选择框、按钮和图标按钮统一使用 40px 控件高度、8px 圆角与 12px 正文字号；紧凑按钮和图标按钮使用 30px。
- 卡片使用统一的 12px 圆角、细边框和留白。主操作、次操作、轻量操作、危险操作有明确层级；悬停、禁用及键盘焦点采用同一套规则。
- 滑块集中为 `RangeSlider`：4px 轨道、16px 手柄、28px 操作区域、按数值计算的进度填充。提供 WebKit 与 Firefox 样式，颜色随主题变量变化。
- 滑块保留原生 `input[type=range]` 的键盘与数值语义，并透传原有 change、释放、失焦和键盘事件。人物尺寸保存的去抖、串行与补写逻辑未改。
- 全局滚动条统一为细窄、中性、无渐变的样式，悬停略加深；支持 WebKit 的平台移除两端箭头。页面不再各自设置不同滚动条颜色。
- 复选框、颜色选择器、搜索框、分段切换、空状态和提示框共用视觉规则。没有新增 UI 框架、字体下载或运行依赖。

## 各界面接入

| 界面 | 调整 |
| --- | --- |
| 人物 | 输入、选择、文本域、导入、删除、保存、卡片和尺寸滑块接入共享样式；资源要求改为可展开阅读，要求本身不变 |
| 聊天 | 统一消息气泡和输入区；长文本可换行、可选择复制；发送/停止按钮与全局操作一致 |
| 记忆 | 统一视图切换、日期卡片、历史正文、搜索、复制、删除与存档操作 |
| 主题 | 保留全部主题及颜色编辑；主题选择改为原生按钮，删除按钮独立，使用共用操作按钮 |
| 设置、指南、首次引导 | 延续前一轮统一框架，并继承相同控件高度、焦点及滚动条规则 |
| 工具箱 | 去掉装饰渐变与光晕，统一表面、边框、图标和按钮；缩短过长的拖动提示 |

工具箱启动按钮补充 Enter/空格键盘操作与可见焦点。人物存档的编辑、切换也改为真正的按钮，不再使用可点击 span。旧主题专属按钮 CSS 及无引用的背景颜色兼容覆盖已删除，避免共享样式与旧样式叠加。

## 额外修复

浏览器预览的人物页原先直接调用 `getCurrentWebview()`，同步读取原生元数据时可能在 Promise catch 前抛错，导致白屏。现在先判断桌面运行环境。原生桌面拖放事件监听和导入逻辑保持不变。

## 测试边界

- 实际使用 Edge 渲染真实组件与样式并检查截图及 DOM 尺寸；截图数据为虚构人物、聊天及密钥标识。286px 测试直接设置实际面板宽度，关闭仅用于 QA 的入场动画，避免变换缩放干扰尺寸读数。
- 没有使用用户真实密钥调用付费 API，也没有在真实数据库中新增或删除配置/人物。
- 新截图和浏览器配置在已忽略的 D 盘项目 QA 目录中。未安装应用或新依赖，main 未动。
- Firefox 提供对应控件 CSS，但本轮没有 Firefox/macOS 实机验收；不同操作系统下的原生弹出菜单仍可能保留系统样式。
