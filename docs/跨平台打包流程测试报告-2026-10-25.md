# 跨平台打包流程本地测试报告

日期：2026-10-25。测试起始分支：`codex/simplify-companion`。后续经用户授权，将本轮完整改动提交到 main；不创建标签或发布 Release。远端构建状态以 GitHub Actions 为准。

## 本轮变更

- 同一 workflow 显示名改为 `Build Desktop (Windows & macOS)`；保留原文件路径，避免新增重复流程。
- 新增 Windows x64 任务，与 Mac Intel / Apple Silicon 并行构建；支持 main 推送、手动和 `v*` 标签触发，不监听其他开发分支推送。
- Windows 显式输出 NSIS EXE / WiX MSI，当前用户 NSIS 安装、中英语言选择、缺少 WebView2 时联网安装；构建工具缓存在项目 target 目录。
- Windows 新增 CI 专用检查：应用 PE 架构与版本、安装包数量与命名、release 应用进程存活、SHA-256 校验文件和限范围 Artifact 上传。
- 新增平台配置严格反序列化回归测试、同步 README 与操作指南。
